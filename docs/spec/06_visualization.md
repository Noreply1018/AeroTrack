# 06. 可视化规格

## 可视化目标

可视化模块负责把检测、跟踪和评估结果转化为可检查、可汇报、可复核的图像或视频材料。可视化不是模型运行的副产物，而是实验基线的一部分。

## 输入

可视化模块只读取项目统一产物：

1. 样本索引。
2. 原始或转换后的 Range-Angle 图像。
3. 统一检测结果。
4. 统一跟踪结果。
5. 评估失败样例线索。

## 检测可视化

检测可视化应展示：

1. 检测框。
2. 类别名或类别 ID。
3. 置信度。

输出可以是单帧图像，也可以是按序列组织的帧目录。

## 跟踪可视化

跟踪可视化应展示：

1. 跟踪框。
2. `track_id`。
3. 类别信息。
4. 可选轨迹线。

颜色应尽量按 `track_id` 稳定分配，便于观察 ID 连续性。

## 轨迹回放

轨迹回放应支持按序列导出视频或帧序列。回放材料用于展示完整检测-跟踪链路，输出路径建议为：

```text
visualizations/
  sequences/
  videos/
```

## 失败样例导出

失败样例导出应覆盖：

1. 漏检。
2. 虚警。
3. ID switch。
4. 跟踪断裂。

每个失败样例应能关联到 `sequence_id` 和 `frame_id`，便于回到原始样本复查。

## 输出要求

可视化输出必须写入当前实验目录下的 `visualizations/`，不能覆盖其他实验结果。输出文件名应包含序列和帧信息，避免人工复核时无法定位来源。
