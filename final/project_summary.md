# AeroTrack 项目答辩提纲

## 1. 项目背景及研究意义

AeroTrack 面向 CARRADA 雷达 Range-Angle 数据，目标是在视觉受限场景下建立可落地的目标检测与多目标跟踪流程。雷达数据不依赖光照，适合补足纯视觉方案在夜间、遮挡和复杂天气中的短板，因此有明确的工程价值。

## 2. 项目整体思路与主要工作内容

项目按“数据转换 -> 检测训练 -> 跟踪闭环 -> 指标评估 -> 展示归档”推进。主要工作包括：

- 将 CARRADA 原始 Range-Angle 数据转换为可训练的 PNG 和 YOLO 标注格式。
- 完成本地 YOLOv8n 训练、验证和推理展示。
- 将基于标注转换的跟踪验证结果接入连续帧轨迹展示。
- 汇总训练曲线、推理样例、跟踪结果和消融实验，形成答辩材料。

## 3. 阶段性成果、实验结果或作品展示

当前展示包已经整理出三类核心成果：

| 成果 | 结果 |
| --- | --- |
| 数据转换 | 10 个 sequence，5727 张 RA 图，2425 个标注框 |
| 检测训练 | YOLOv8n 已完成 30 个 epoch，保留训练曲线和推理图 |
| 跟踪闭环 | 已生成连续帧可视化、参数消融和规模对比结果 |

## 4. 项目创新点、实际应用价值或特色亮点

- 将雷达 RA 图与通用检测框架对接，降低后续算法替换成本。
- 保留了“真实 YOLO 训练结果”和“标注驱动的跟踪闭环”两条证据链，口径清晰。
- 用统一中间结果支撑跟踪、评估、可视化归档，便于扩展到更大规模数据。

## 5. 项目推进过程中遇到的问题及解决思路

| 问题 | 处理思路 |
| --- | --- |
| 训练资源受限，模型精度提升有限 | 保留真实训练曲线与推理图，展示工程链路而非夸大精度 |
| 检测结果和跟踪闭环容易混淆 | 将真实检测结果与基于标注转换的跟踪验证分开展示 |
| 跟踪参数对结果影响明显 | 通过消融实验说明 IOU、`max_age`、`min_hits` 的影响 |

## 结论口径

- 已完成 RA 数据转换、YOLO 检测训练、跟踪验证、指标评估和可视化归档。
- 现阶段成果更适合定义为工程验证和展示样例。
- 后续提升重点在检测精度、ID 一致性评估和更大规模训练。
