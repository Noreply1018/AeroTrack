# 最终展示报告

## 展示主线

建议答辩围绕“为什么做这个项目、如何把雷达数据接到通用检测跟踪框架、已经做出哪些可见结果、目前还存在哪些约束”展开。主图应同时说明 RA 图、检测框和轨迹输出之间的关系。

## 1. 项目背景及研究意义

雷达 Range-Angle 图适合在视觉受限环境下补充感知能力。AeroTrack 的意义在于把原始雷达数据转成可训练、可评估、可展示的标准流程，让后续检测和跟踪可以在统一中间格式上扩展。

## 2. 项目整体思路与主要工作内容

| 环节 | 说明 | 展示重点 |
| --- | --- | --- |
| 数据转换 | 将 CARRADA 原始数据整理为 RA PNG 和 YOLO 标签 | 数据规模、标注抽查图 |
| 检测训练 | 使用 YOLOv8n 做本地训练与验证 | 训练曲线、PR 曲线、推理样例 |
| 推理展示 | 选取样例图展示模型输出效果 | 目标框可视化 |
| 跟踪闭环 | 用标注转换后的结果连接连续帧目标轨迹 | 连续帧轨迹、参数影响 |

## 4. 项目创新点、实际应用价值或特色亮点

- 把雷达 RA 表征接入通用 YOLO + 跟踪链路，工程路径清晰。
- 将真实 YOLO 训练结果与基于标注转换的跟踪验证分开呈现，口径更严谨。
- 通过消融实验说明跟踪参数对连续轨迹的影响，便于后续优化。

## 5. 项目推进过程中遇到的问题及解决思路

| 问题 | 解决思路 |
| --- | --- |
| 训练速度慢，精度提升有限 | 以真实训练曲线和推理样例证明流程完整，不夸大结论 |
| 检测结果和跟踪闭环容易混淆 | 分层展示，真实检测结果与跟踪验证分开叙述 |
| 跟踪效果对阈值敏感 | 用参数消融解释 MOTA 变化 |

## 结论

当前展示包适合支撑结项答辩，重点是“数据、方法、结果、价值、问题处理”五件事。答辩时建议只使用图片、表格和结论页。
