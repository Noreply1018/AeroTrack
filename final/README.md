# AeroTrack 最终答辩展示包

本目录只保留面向评委展示的图片、表格和结论材料。展示重点是说明项目为什么做、怎么做、做出了什么、价值在哪里、问题如何解决。

## 一页总览

| 展示维度 | 建议使用的内容 | 答辩结论 |
| --- | --- | --- |
| 项目背景及研究意义 | 主图、背景说明页 | 毫米波雷达在弱光、雨雾等视觉受限场景仍能感知目标，AeroTrack 聚焦 Range-Angle 雷达图上的检测与跟踪闭环。 |
| 整体思路与主要工作 | 技术路线页、数据转换图、主流程图 | 项目形成了“RA 数据转换 -> YOLO 检测训练 -> SORT 跟踪 -> 指标评估 -> 可视化归档”的完整流程。 |
| 阶段性成果与实验结果 | 训练曲线、推理样例、连续帧跟踪图、数据规模表 | 已完成 5727 张 RA 图、2425 个标注框的数据转换，完成 YOLO 训练与推理展示，并完成连续帧跟踪可视化。 |
| 创新点和应用价值 | 消融图、方法总结页 | 将雷达 RA 表征接入通用检测模型与跟踪算法，用统一中间结果支撑后续替换更强检测器。 |
| 问题及解决思路 | 问题分析页、诊断边界图 | 当前 YOLO 小规模训练精度有限，因此用真实 YOLO 结果说明检测链路，用标注驱动的跟踪闭环单独验证后处理。 |

## 推荐展示顺序

1. 背景与意义：先展示主图，说明雷达 RA 图、检测框和轨迹之间的关系。
2. 数据与方法：先讲清数据规模，再展示标注抽查图。
3. 检测结果：展示训练曲线和推理样例，强调链路已打通。
4. 跟踪结果：展示连续帧轨迹图，说明时序关联效果。
5. 消融与问题：展示参数消融图和诊断边界图，说明局限和下一步优化。

## 材料边界

训练曲线和推理样例来自真实 YOLO 输出，可用于说明检测链路已经打通。连续帧跟踪图来自基于标注转换的闭环验证，用于展示下游跟踪、评估和可视化能力，不能把其中的检测指标当作 YOLO 模型精度。
